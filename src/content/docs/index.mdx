No programming experience needed: you'll learn **Go Lang** by building a real
**todo web app** — a command-line tool, a web API, and a browser interface —
one small piece a day, with tests that keep the code honest along the way.

<div id="tracker-overview"></div>

## Build a real todo app in Go

Over 100 days you'll write a complete application from an empty folder: a
**Golang CLI** with cobra, a **REST API** with echo, a server-rendered **web
UI** with templ, a **terminal UI** with Bubble Tea, and a database layer with
Turso and sqlc — plus the tests, security work, and deployment that hold it
all together. Every command and every line of output in the lessons comes
from a real run of the finished app.

## Learn Go Lang from zero

The course assumes no programming experience. You start with your first
failing test and end with a released application: structs, interfaces,
generics, concurrency, context, SQL, HTTP, sessions, and observability —
each introduced exactly when the app needs it.

## How the 100 days work

All 100 days are written — 84 build days and 16 review days, about two to
three hours each. They take the app from an empty folder to a production
system, then go underneath it with data structures and algorithms.
[Start here](/100-days-of-go-lang/start-here/) explains the rhythm, or jump
straight to [Day 1 — The first test](/100-days-of-go-lang/days/day-01/). Your
progress is saved in your browser, and the whole book works offline once
installed.

## Frequently asked questions

**Is this Go course free?** Yes — the whole book is free to read online,
with no sign-up and no account.

**Do I need programming experience?** No. The course starts from an empty
folder and assumes nothing beyond a terminal, an editor, and Go 1.26 or
newer.

**What will I build?** A complete todo app in Go Lang: a command-line tool,
a REST API, a server-rendered web UI, and a terminal UI — with a database,
tests, authentication, and deployment.

**How long does the course take?** About two to three hours a day. All 100
days are written: the app, its production ground, and the data structures and
algorithms stretch.

**Is this book really written by an AI?** Yes. The prose is machine-written;
every command and transcript in it was executed and verified for real. The
[disclaimer](/100-days-of-go-lang/disclaimer/) explains exactly what that
means.
