## Written with

- **An AI assistant, running in [OpenCode](https://opencode.ai)** — the agent
  harness that planned the course, wrote the lessons, ran the builds, and
  checked every quote and transcript against the application. This edition
  was written with **DeepSeek V4.1 Flash**.
- **A human in the loop** — who set the goals, reviewed the result, and
  decided what shipped.

## The site built with

- **[Astro](https://astro.build)** and
  **[Starlight](https://starlight.astro.build)** — the framework and theme
  the book site is made of.
- **[Bun](https://bun.sh)** — the runtime and package manager that builds
  and tests everything here.
- **[Expressive Code](https://expressive-code.com)** and
  **[Shiki](https://shiki.style)** — the code blocks and their warm syntax
  themes.
- **[Pagefind](https://pagefind.app)** — the offline full-text search.
- **[sharp](https://sharp.pixelplumbing.com)** — the app icons.
- **[0xProto](https://github.com/0xType/0xProto)** by 0xType — the typeface,
  under the SIL Open Font License.
- **Noto Sans Symbols 2** — the symbol fallback for captured tool output,
  under the SIL Open Font License.

## The application built with

Go, of course — and a stack the book introduces one piece at a time: Turso,
echo, templ, sqlc, goose, cobra, scs, argon2id, uuid, testify, go-cmp,
go-snaps, moq, Bubble Tea, Lip Gloss, OpenTelemetry, Prometheus, and
GoReleaser. [Beyond this book](/100-days-of-go-lang/appendices/beyond-this-book/) has the fuller
list, with the alternatives each one had.

## Thanks

To the Go team, to the maintainers of every library above, and to everyone
who writes the documentation the rest of us read. And to you, for reading
something a machine wrote — carefully, we hope.
